##  Core Claim
For the IFS consisting of two affine maps:
- $f_1(x,y,z) = (z, x/2, y)$
- $f_2(x,y,z) = (z, x/2 + 1/2, y)$

The set $S = [0,1]^3$ is an invariant set: $f_1(S) \cup f_2(S) = S$.
